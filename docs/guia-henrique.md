# Guia rápido — Central Mendes & Vaz Social

Bem-vindo! Esse sistema gera 3 variações de post pro Instagram do escritório
em ~2 minutos a partir de um briefing curto. Você escolhe a melhor, ajusta
se quiser, aprova, e baixa o pacote pronto pra postar.

## 1. Acessando

- **Link:** https://content-agent-vrz77a.fly.dev
- **Usuário e senha:** enviados separadamente pelo Enzo.

Na primeira vez o navegador vai pedir login (caixa branca pequena no topo).
Depois ele lembra por algumas horas.

## 2. Como gerar 1 post (5 passos)

1. Clique em **"Nova campanha"** no canto superior direito.
2. Preencha o briefing (7 campos):
   - **Área do direito** (ex.: "Direito Médico")
   - **Perfil do cliente ideal** (ex.: "Médicos de BH preocupados com processos")
   - **Tom** (Técnico / Acessível)
   - **Objetivo** (Posicionamento / Awareness / Captação)
   - **Formato** (Square / Portrait / Story / Carrossel)
   - **Nº de slides** (só pra carrossel)
   - **Tema específico** (opcional — deixe vazio se quiser deixar a IA escolher)
3. Clique **"Gerar"**. Aparece "Gerando..." por ~1-2 minutos.
4. Quando terminar, aparecem **3 opções de post** lado a lado.
5. Escolha a melhor → **"Aprovar"** → defina a data de agendamento →
   clique **"Exportar"** pra baixar imagem + legenda em ZIP.

## 3. Editando antes de aprovar

Se quiser ajustar a copy gerada (mudar palavra, encurtar headline):
- Clique no texto que quer editar dentro da opção
- Edite no campo que aparece
- Clique fora pra salvar (auto-save)
- A imagem regenera sozinha em ~20 segundos

## 4. Se algo der errado

| Sintoma | O que fazer |
|---|---|
| Campanha trava em "Gerando..." por mais de 5 min | Recarrega a página (F5). Se continuar, avisa o Enzo. |
| Imagem com texto bugado / cortado | Reporta pro Enzo com o ID da campanha |
| Erro vermelho na tela | Tira print + manda no WhatsApp do Enzo |
| Esqueci a senha | Mensagem pro Enzo, ele reseta em 1 min |

## 5. Limites mensais

Pra não disparar custo de API sem querer, há limites no sistema:
- **Campanhas por mês:** ver no rodapé da página
- **Campanhas agendadas pro futuro:** mesmo lugar

Se bater o limite, avisa o Enzo — fácil de aumentar.
